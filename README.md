# Two Words

## **ABSTRACT**

*Two Words* is a short story I created a while ago, which I've now transformed into an interactive story that's more engaging through React.js. The inspiration for this project came from the idea of how visual memory is incredibly malleable and how, when reading a story, we always imagine different visuals. The structure is quite simple, with the story in the center that can be scrolled and images that can be dragged to the side. The guide is also clear, with instructions at the beginning and numbers to give hints on what the user needs to do. The images are relevant to the story and help build the narrative, while also giving the reader more freedom by allowing them to add their own images. As I love short stories, I hope this project can serve as a medium to grow the world's love for reading.
